# Project: ITSM Workflow Automation & Orchestration

## Executive Summary
Architected and restructured a self-hosted Zammad ticketing instance to optimize support operations. The project focused on eliminating manual triage by implementing automated routing, specialized group assignments, and custom organizational overviews.

## Problem Statement
Standard help desk deployments often suffer from inefficient ticket routing and poor visibility into specialized project requests, leading to delayed response times and administrative overhead. 

## Technical Implementation
*   **Infrastructure:** Deployed and maintained the Zammad instance within a secure, self-hosted containerized Docker stack on an Unraid server environment.
*   **Workflow Automation:** Engineered automated triggers to dynamically process incoming files and assign administrative roles based on request criteria.
*   **Routing & Organization:** Introduced specialized support groups and automated tagging workflows to ensure tickets are instantly routed to the correct escalation tier.
*   **Visibility Optimization:** Developed custom overviews tailored specifically for tracking and managing project proposals.

## Key Takeaways
*   **Operational Efficiency:** Demonstrated the ability to transform a raw ITSM tool into a highly automated, business-aligned support platform.
*   **Process Engineering:** Showcased a deep understanding of ticketing lifecycle management, automated triage, and role-based access control.
