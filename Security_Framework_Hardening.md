# Project: Security Framework Implementation & Hardening

## Executive Summary
Executed a structured security hardening project mapping technical controls to NIST 800-171 v2 requirements to mitigate unauthorized access and data exfiltration.[cite: 13]

## Problem Statement
Standard deployments often operate with default configurations that are vulnerable to exploitation.[cite: 13] The objective was to transition from "functional" infrastructure to a "hardened" security posture.[cite: 13]

## Implementation (Technical Controls)
*   **Network Segmentation:** Implemented VLAN isolation for IoT devices, management interfaces, and production workloads to prevent lateral movement.[cite: 13]
*   **Identity & Access Management (IAM):** Enforced MFA for all remote access points and transitioned to a "Zero Trust" model for internal service access.[cite: 13] Integrated YubiKey hardware security keys to provide phishing-resistant endpoint authentication.
*   **Data at Rest Protection:** Enforced Windows 11 Pro BitLocker drive encryption across managed 13.5-inch Surface Book 3 endpoints to prevent physical data extraction.
*   **Audit & Logging:** Configured centralized logging for system events to enable timely detection of anomalous behavior or unauthorized access attempts.[cite: 13]
*   **Patch Management:** Established a consistent cadence for firmware/OS vulnerability remediation based on CVE analysis.[cite: 13]

## Framework Alignment
*   **NIST 800-171 v2:** Aligned infrastructure controls with stringent standards for protecting Controlled Unclassified Information (CUI).[cite: 13]
*   **Principle of Least Privilege:** Strictly enforced access controls, ensuring services only possess the permissions necessary for operation.[cite: 13]

## Key Takeaways
*   **Risk-Based Approach:** Shifted from "ad-hoc" security to a structured, framework-aligned strategy.[cite: 13]
*   **Security-by-Design:** Demonstrated the ability to integrate security controls into the build process rather than retrofitting them as an afterthought.[cite: 13]
*   **Regulatory Awareness:** Developed foundational knowledge in mapping technical configurations to high-level compliance requirements.[cite: 13]
